# ACCJC directory of institutions (web)

## Citation

Accrediting Commission for Community and Junior Colleges (ACCJC). "ACCJC Directory of Institutions: Find an Accredited Institution." Web page, page timestamp 2026-09-09. https://accjc.org/find-an-institution/. Read 2026-11-12.

## Bottom line

- The ACCJC directory lists 139 institutions, with the city, the type and the accreditation status of each.
- The directory gives "California" as the state of 124 of them. The others are seven in Hawaii, one each in Arizona, Nevada and New York, and five with no state, for example "Guam Community College".
- 132 have the status "Accredited". Five have "Initial Accreditation", one has "Warning" and one has "Candidacy".

## Background

ACCJC is an accreditor of community and junior colleges, with an office in Sacramento. The directory page has filters by institution, staff liaison, degree, state, city and status. Below the filters, it lists each institution with its city, type, status, staff liaison and degree types. The counts on this page come from the library's count of the rows in the copy of Nov. 12, 2026.

## Key claims

- Heading: "ACCJC Directory of Institutions" and "Find an Accredited Institution". (page heading)
- Status values: the status filter gives "Accredited", "Candidacy", "Initial Accreditation", "Probation", "Show Cause", "Terminated" and "Warning". (Accreditation Status filter)
- Example row: "Allan Hancock College", "Santa Maria", "Public (state/local) two-year", "Accredited". (first row)
- Types: 124 rows have the type "Public (state/local) two-year". Other types are "Private", "Private (profit)", "Private (non-profit) two-year", "Tribal" and "Public (federal) two-year". (rows)
- Rows not "Accredited": "California Indian Nations College" ("Tribal", "Initial Accreditation"), "Mount Tamalpais College" in "San Quentin" ("Initial Accreditation"), "Theoria Technical College" ("Candidacy") and "College of the Marshall Islands" ("Warning"). (rows)
- Degrees: the degree filter includes "Associate of Arts for Transfer", "Bachelor of Science" and "Short-Term Credential". (Degree filter)

## Evidence and method

This is a directory page of an accrediting body. It gives one row for each institution, from the accreditor's own records. The library counted the rows in the Markdown copy; the page itself prints no totals. Each row links to an institution detail page, which the library has not read.

## Limits

- The page gives no web address, county or coordinates for an institution.
- It does not say which institutions are in the California Community Colleges system.
- It gives no date for each status, and no reason for a "Warning" status.
- The page shows staff liaison names. This library does not repeat them.
