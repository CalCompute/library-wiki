# GitHub Acceptable Use Policies (web)

## Citation

GitHub. "GitHub Acceptable Use Policies." Site policy page, GitHub Docs, date not stated. https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies. Read 2026-11-12.

## Bottom line

- The GitHub Acceptable Use Policies have 11 sections on the content and conduct that GitHub does not allow.
- They bar cryptocurrency mining as "automated excessive bulk activity" and bar use of GitHub servers to attack or get unauthorized access to systems.
- Researchers may use public, non-personal information from GitHub only if the resulting publications are open access.

## Background

GitHub publishes these policies in the Site policy section of GitHub Docs. They apply under the GitHub Terms of Service, the GitHub Customer Agreement, the Corporate Terms of Service or a Microsoft volume licensing agreement. The GitHub Terms of Service are in the library as [GitHub Terms of Service (web)](GitHub%20Terms%20of%20Service%20%28web%29.md).

## Key claims

- Summary: "While using the Service, you must comply with our Acceptable Use Policies, which include some restrictions on content and conduct on GitHub related to user safety, intellectual property, privacy, authenticity, and other limitations." (Short version)
- User safety: GitHub does not allow content or activity that "is unlawful or promotes unlawful activities" (Section 2)
- Bulk activity: GitHub does not allow "automated excessive bulk activity and coordinated inauthentic activity, such as" "spamming" and "cryptocurrency mining" (Section 4)
- Site safety: GitHub does not allow content or activity that "uses our servers to disrupt or to attempt to disrupt, or to gain or to attempt to gain unauthorized access to, any service, device, data, account or network." (Section 5)
- Resale: "You will not reproduce, duplicate, copy, sell, resell or exploit any portion of the Service, use of the Service, or access to the Service without our express written permission." (Section 6)
- Research use: "Researchers may use public, non-personal information from the Service for research purposes, only if any publications resulting from that research are open access." (Section 7)
- Bandwidth: GitHub reserves "the right to suspend your Account, throttle your file hosting, or otherwise limit your activity until you can reduce your bandwidth consumption." (Section 9)
- Enforcement: "GitHub retains full discretion to take action in response to a violation of these policies, including account suspension, account termination, or removal of content." (Enforcement)

## Evidence and method

This is the text of a platform usage policy. The library read all 11 sections and the enforcement and appeal notes. It gives categories of conduct that GitHub does not allow. It links to separate pages for each category, such as malware and misinformation. The library did not read those pages.

## Limits

- The page gives no date.
- It does not give numeric limits for bandwidth or bulk activity. It refers to the GitHub Additional Product Terms.
- It gives no rules on the use of GitHub AI features. Those are in Section J of the Terms of Service.
