# CDT California Managed Cloud CAMC (web)

## Citation

California Department of Technology. "California Managed Cloud (CAMC)." Service web page. https://www.cdt.ca.gov/services/camc/. Copy: [`raw/web/2026-11-11 CDT California Managed Cloud CAMC.md`](../../raw/web/2026-11-11%20CDT%20California%20Managed%20Cloud%20CAMC.md) (original: `.html` beside it). Read 2026-11-11. No date on the page.

## Bottom line

- California Managed Cloud (CAMC) gives California government organizations Infrastructure as a Service (IaaS) from providers "like Azure and AWS". The California Department of Technology (CDT) runs it as a state-compliant environment.
- CAMC bills the cloud provider's cost plus a 17% fee, and $801 for each virtual machine each month for CDT support. A CAMC user does not need the California Cloud Services Assessment (CCSA).

## Background

CAMC is one of the California Cloud Services that CDT offers to state entities ([CDT cloud services (web)](CDT%20cloud%20services%20%28web%29.md)). It has two models: CDT Managed and Self-Managed. The page gives the features, rates, the request steps and answers to common questions.

## Key claims

- "California Managed Cloud (CAMC) offers a public cloud experience for California government organizations – delivering Infrastructure as a Service (IaaS) through trusted providers like Azure and AWS." (Why CAMC?)
- "Because CAMC environments (CDT managed or Self-managed) are already secured and fully compliant with State IT security requirements, you can bypass the California Cloud Services Assessment (CCSA) process." (Why CAMC?)
- "Environments compliant to SOC, FISMA, PCI DSS, ISO, and FedRamp Moderate standards" (What’s included?)
- Rates: "CAMC Pass-Through | Variable | Vendor Cost +17% Fee"; "CAMC Windows IaaS Support | Per IaaS VM Instance, Per Month | $801.00"; "CAMC Linux IaaS Support | Per IaaS VM Instance, Per Month | $801.00" (Rates)
- "A 17% Administrative Support Fee pays for shared services that keep your platforms secure and compliant": "4.58% – VHSS" and "12.19% – CAMC Cloud Services team + CAMC infrastructure/software" (FAQ 5)
- "Generally, it takes a couple of days to have a scoping meeting to determine your needs and then build to those specifications." (FAQ 1)
- Request steps: contact the CDT Account Lead, then "submit a California Managed Cloud (CAMC) Services Case/Request in the CDT IT Service Portal" (Discovery or New CAMC enrollment)

## Evidence and method

A service catalog page from a state department. It gives the rate table and the parts of the 17% fee. It gives no usage figures, customer counts or contract terms with the cloud providers.

## Limits

The page does not name GPU instances or AI services. It does not say which state contracts the Azure and AWS services come through. It says "providers like Azure and AWS", so the list can be longer. The companion page says that "CDT’s cloud services uses VMWare Virtual Cloud Foundation (VCF) Infrastructure as a Service (IaaS)" ([CDT cloud services (web)](CDT%20cloud%20services%20%28web%29.md)). Neither page explains how the two fit together.
