# C2C Request Access to Data (web)

## Citation

California Cradle-to-Career Data System. "Request Access to Data." Web page. https://c2c.ca.gov/request-access-to-data. No date on the page; footer "Copyright © 2026".

## Bottom line

- C2C sets three levels of access to its data. Public tools need no review, aggregate data gets an expedited review, and individual-level data gets a comprehensive review.
- The page gives target times: one month for an expedited data file and three months for preliminary approval of a comprehensive request. It says the request process is "Coming soon".

## Background

The California Cradle-to-Career Data System (C2C) links education, workforce and social service data that its data partners already hold. This page describes its data request process. The page says that the Data and Tools Advisory Board reviews the process after the first year. It then reviews the approved and denied requests each year.

## Key claims

- "Coming soon, researchers will be able to request access to the information needed to conduct complex analyses and evaluate programs." (Request Access to Data)
- "Requests for de-identified aggregate data that are not available through the query builder will require a data request form to be filled out, reviewed by the managing entity, and approved by the relevant data providers. Data provided through the expedited process should not require a legal agreement." (Expedited Review Process)
- "Requests for anonymized individual-level data will require a comprehensive review." The requestor signs "a legal agreement and provide proof of research training" (Comprehensive Review Process)
- "Documentation will be posted on the Cradle-to-Career System website to provide a list of all requests for data, who made each request, the project abstract, and the status of each request." (Request Access to Data)
- "Expedited Review: One month to receive a data file"; "Comprehensive Review: Three months to receive preliminary approval" (review tiers)
- "The Office of Cradle-to-Career Data does not collect new data from students or families." (How we use data)

## Evidence and method

A program web page that describes a process. It gives target times for each tier. It gives no counts of requests, approvals or users.

## Limits

The page does not say when the request process opens. It does not describe the secure data enclave or its vendor. It gives no fees. The page calls individual-level data "anonymized", while the staff report calls it "deidentified" ([C2C DTAB 5 research request and secure enclave update (web)](C2C%20DTAB%205%20research%20request%20and%20secure%20enclave%20update%20%28web%29.md)).
