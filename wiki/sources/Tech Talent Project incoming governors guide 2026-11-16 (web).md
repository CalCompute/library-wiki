# Tech Talent Project incoming governors guide 2026-11-16 (web)

## Citation

Betsy Beaumon, Tech Talent Project. "New Interactive Guide, Playbooks, and Tech Leaders Help Incoming Governors Hire Leaders and Improve State Services." Tech Talent Project blog, Nov. 16, 2026. https://techtalentproject.org/new-interactive-guide-playbooks-and-tech-leaders-help-incoming-governors-hire-leaders-and-improve-state-services/. Read 2026-11-19.

## Bottom line

- Tech Talent Project released an Interactive Transition Guide for the 21 states with new governors in January 2027. The guide draws on its nine 2026 State Memos for a Tech Transition.
- It offers state transition teams embedded tech leaders and executive recruiting "at no cost to the state". The AI memo calls for a senior AI leader in the first 30 days.

## Background

The post is a release on the blog of Tech Talent Project. It describes the guide, the memos and the Tech Leaders in Residence service. Tech Talent Project wrote the memos with the American Enterprise Institute, the Beeck Center at Georgetown University and the New America New Practice Lab. The program page is [Tech Talent Project state transitions (web)](Tech%20Talent%20Project%20state%20transitions%20%28web%29.md).

## Key claims

- "With 21 states set to have new governors in January 2027, Tech Talent Project today released an Interactive Transition Guide that lays out first-100-day actions and insights drawn from its 2026 State Memos for a Tech Transition." (first paragraph)
- "It can embed a senior leader who has built and run government tech into the transition team for 45 to 60 days or set up a call with an expert who has done the work in a particular area such as cybersecurity." "All of it is at no cost to the state." (second paragraph)
- "For incoming governors, AI readiness is a hiring question before it’s a tech question. Ninety percent of states have started generative AI pilots, but Code for America rates no state “Advanced” on impact and 26 still “Early” on implementation." (What the Interactive Transition Guide and memos cover)
- "The AI memo calls for designating and empowering a senior AI or emerging tech leader in the first 30 days, and outlines critical questions and actions for them to address based on where the state is starting." (What the Interactive Transition Guide and memos cover)
- "Indiana, for example, hired a Chief Data Officer and built an enterprise office to govern and share state data, reducing reliance on contractors and saving approximately $1 million annually in infrastructure maintenance and support costs." (Why tech capacity matters)
- "Tech Talent Project has matched more than 200 tech and data leaders with government roles, drawn from a network of more than 11,000 technologists, and has placed leaders or provided other support in 30 states, including Maryland, Nebraska, New York, Pennsylvania, and Wyoming." (About Tech Talent Project)

## Evidence and method

An organization's release. It describes a new product and quotes five people from Tech Talent Project and its partners. It cites Code for America for the state AI ratings but gives no link or date for them.
