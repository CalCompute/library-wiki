## Bottom line

- The California Cradle-to-Career Data System (C2C) gives data to researchers in three tiers: the Query Builder, Expedited Data Requests and Comprehensive Data Requests.
- A secure data enclave is to give approved researchers "a secure compute environment" for deidentified individual-level data. In Sept. 2025 the Office was still defining its scope and pilot users.

## Background

This is a staff report for the C2C Data and Tools Advisory Board (DTAB), agenda item 5, for information only. Education Code section 10866(b)(6) tells the Governing Board to create a data request process with the advisory boards. Attachment A is a draft Research Request Intake Form, with requestor, project and open science questions.

## Key claims

- "The Research Request Process employs a three-tiered system to facilitate data requests that enable the California public to use data in the system to conduct research that addresses disparities in opportunities in student outcomes. The three tiers are the Query Builder, Expedited Data Requests, and Comprehensive Data Requests." (p. 1)
- "As part of the research request process, the secure data enclave will provide researchers with a secure compute environment to analyze deidentified individual level data for approved research requests." (p. 3)
- "Currently, the Office is defining the scope of the data tools for researchers to use in the secure data enclave, including statistical programming tools. The Office is working on identifying a set of candidate users to pilot the secure data enclave." (p. 3)
- "If approved, requestors will sign a legal agreement and provide proof of research training (e.g., Collaborative Institutional Training Initiative (CITI) Program). C2C staff and Data Providers will review analytical outputs to ensure data privacy." (Attachment A, p. 1)
- The query builder's first phase was "released it to the public on September 16, 2025." (pp. 2 to 3)

## Evidence and method

A staff report to a state advisory board. It describes the Office's work and asks board members questions. Attachment A is a draft form, with requestor types from "Advocacy Organization" to "Postsecondary Institution/System" and pre-registration questions. The report gives no numbers of requests or users.

## Limits

The report predates the enclave's pilot and does not name a vendor. [NORC Cradle-to-Career data enclave (web)](NORC%20Cradle-to-Career%20data%20enclave%20%28web%29.md) says that C2C chose the NORC Data Enclave. The report gives no review times, costs or approval rates.
