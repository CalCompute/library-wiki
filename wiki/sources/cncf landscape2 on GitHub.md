# cncf landscape2 on GitHub

## Citation

Cloud Native Computing Foundation (CNCF). https://github.com/cncf/landscape2. Read 2026-10-15.

## Bottom line

- landscape2 is a free, open-source command line tool that builds a static, interactive landscape website from YAML (a plain-text data format) files.
- It is a tool, not evidence about California compute. It gives the Report no facts.
- That is a presentation choice for the group.

## Background

The CNCF uses landscape2 to build the CNCF landscape at landscape.cncf.io. A separate repository lists other landscapes built with it.

## Key claims

- The tool "generates static websites from the information available in the data sources provided": a landscape data file, a settings file, a guide file, a games file and a logos location, all YAML except the logos.
- Crunchbase use "requires an Enterprise or Application license".
- Subcommands: `build`, `deploy` (experimental), `new`, `serve` and `validate`.
- The output is a single-page application. A static site service such as GitHub Pages can host it.
- Other sites can embed views of one or more categories.
- Licence: Apache License 2.0.
