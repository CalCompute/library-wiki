# CDT State IT class career path salary ranges 2023-07-01 (web)

## Citation

California Department of Technology (CDT). "State IT Class Series Career Paths & Salary Ranges as of July 1, 2023." One-page chart, PDF, November 2023. https://www.cdt.ca.gov/wp-content/uploads/2023/11/State-IT-Class-Career-Path-Salary-Ranges.pdf. Read 2026-11-19. Copy: `raw/web/2026-11-19 CDT State IT class career path salary ranges 2023-07-01.pdf`.

## Bottom line

- The chart gives the monthly pay range of each of nine state information technology (IT) classes on July 1, 2023.
- The lowest range is $3,896 to $5,220 (IT Technician, Range A). The highest is $10,734 to $13,048 (IT Manager II).

## Background

CDT published the chart in November 2023. It shows a technical path and a supervisory path through the state IT class series, and the movement between the two. Each class has its class code and its collective bargaining identifier (CBID).

## Key claims

- "State IT Class Series Career Paths & Salary Ranges as of July 1, 2023" (title)
- "Indicates the paths for either a technical or supervisory career. The levels shown are based upon the maximum salary range for each classification." (legend)
- "Indicates the optional movement between the technical and supervisory paths to gain broader experience. Movement between the paths would typically be by examination." (legend)
- "Entry & Learning Level | 1400 | R01* Information Technology Technician Range A: $3,896 - $5,220 Range B: $4,227 - $5,666 Range C: $4,650 - $6,233" (chart)
- "Working Level | 1401 | R01* Information Technology Associate Range A: $4,651 - $6,234 Range B: $5,113 - $6,852 Range C: $5,589 - $7,491 Range D: $6,147 - $8,238" (chart)
- "Expert Advisor Level | 1415 | M01* Information Technology Specialist III $8,961 - $12,009" (chart)
- "Managerial Level | 1406 | M01* Information Technology Manager II $10,734 - $13,048" (chart)
- "CBID is the three-digit collective bargaining identifier" (footnote)

## Evidence and method

A one-page chart from a state department. It gives the class name, class code, CBID and monthly pay range of each class. It gives no source for the ranges and no count of employees.

## Limits

The ranges are those of July 1, 2023. Later exam bulletins give higher ranges for the same classes. IT Associate Range A is $4,935 to $6,614 ([CalCareers IT Associate exam bulletin EX-1749 (web)](CalCareers%20IT%20Associate%20exam%20bulletin%20EX-1749%20%28web%29.md)). IT Specialist III is $9,230 to $12,369 ([CalCareers IT Specialist III exam bulletin (web)](CalCareers%20IT%20Specialist%20III%20exam%20bulletin%20%28web%29.md)). The chart does not say what each range letter requires, and it gives no benefit or pension costs. It does not name AI or research computing.
