# Berkeley CDSS DataHub page (web)

## Citation

UC Berkeley College of Computing, Data Science, and Society (CDSS). "UC Berkeley DataHub." Web page, no date. https://cdss.berkeley.edu/datahub. Read 2026-11-11. Cached copy: `.cache/web/2026-11-11 Berkeley CDSS DataHub page.md`.

## Bottom line

- DataHub is UC Berkeley's cloud service for course notebooks. It gives on-demand Jupyter and RStudio servers to students in data science courses.
- The page reports more than 4,000 daily users and 16,127 students in 109 courses in 2023-2024. It gives a cloud cost of $5 for each student each semester.

## Background

CDSS runs the Data Science Undergraduate Studies program, which publishes this page. DataHub is the technical base of the Data 8 course. It has several "hub archetypes", for example R Hub and Biology Hub.

## Key claims

What it is (top of page):

- "DataHub is a tool that allows Berkeley's data science program to utilize cloud computing infrastructure to deploy scalable resources that enable users to interact remotely with a standardized, common computing environment."
- "DataHub creates on-demand cloud-based Jupyter notebook and R Studio notebook servers, which are the basis of the technical infrastructure for Data 8 and related courses."

Hub archetypes (section "Hub Archetypes"):

- "Biology hub is a compute-intensive infrastructure tailored towards the needs of instructors in Biology and Genomics."

Principles (section "DataHub Principles"):

- "DataHub is completely free of cost, and no licensing is required for the instructors/students to access the infrastructure."
- "DataHub provides the required infrastructure including the storage and compute in an equitable manner for all students"
- "DataHub was initially piloted in Spring 2017 as part of a small classroom of 50+ students in Data 8."

Metrics (sections "DataHub Metrics" and "UC Berkeley Usage of DataHub"):

- "4000+ DAU daily active users"; "13,000+ MAU monthly active users".
- "$5 Cost cloud costs per student per semester across all hubs".
- "35 departments"; "109 courses"; "16127 students enrolled in the 2023-2024 Academic Year".

## Evidence and method

This is a program page with usage metrics and faculty testimonials. It does not say how it measures the metrics or the cost per student.

## Limits

- The page does not name the cloud provider.
- It does not say who pays the cloud costs.
- It covers Berkeley courses only. Cal-ICOR, a hub for other California campuses, is in [Berkeley VCR Cal-ICOR compute hub launch (web)](Berkeley%20VCR%20Cal-ICOR%20compute%20hub%20launch%20%28web%29.md).
