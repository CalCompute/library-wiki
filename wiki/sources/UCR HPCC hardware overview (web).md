# UCR HPCC hardware overview (web)

## Citation

UC Riverside High-Performance Computing Center (HPCC). "Hardware Overview." HPCC website, last modified Nov. 13, 2026. https://hpcc.ucr.edu/about/hardware/overview/. Read 2026-11-20. Cached copy: `.cache/web/2026-11-20 UCR HPCC hardware overview.md`.

## Bottom line

- The UC Riverside (UCR) HPCC cluster has over 16,000 CPU cores, 60 percent AMD and 40 percent Intel. Each node has 512 to 1,024 GB of memory.
- It lists 86 graphics processing units (GPUs) by model: 2 P100, 24 A100, 2 H100, 16 A6000 Ada and 42 RTX Pro 6000 Blackwell.
- The servers are in a School of Medicine server room of over 600 square feet, with backup power. The backup storage is in a server room at a different location.

## Background

The HPCC runs the shared research cluster of UC Riverside. This page gives short lists for the cluster, the parallel storage, the backup system and the server room. A footer dates its last change to Nov. 13, 2026.

## Key claims

- "Over 16,000 CPU cores (60% AMD, 40% Intel)" and "512-1024GB RAM per node". (Computer cluster)
- "GPU: 2x P100, 24x A100, 2x H100, 16x A6000 Ada, 42x RTX Pro 6000 Blackwell". (Computer cluster)
- "IB network @ 56Gbps - 400Gbps (FDR, HDR and NDR)" and "Queueing system Slurm". (Computer cluster)
- "6PB GPFS storage (scales to >50PB)". (Parallel data storage system)
- Backup system: "6PB GPFS storage" in a "Geographically separated server room". (Backup system)
- "School of Medicine Server Room", "Size 600+ sqft", "Raised floor cooling with redundant AC units" and "Backup power: UPS plus generator". (Server room)

## Evidence and method

A short facility page of about 300 words, with site navigation. It gives totals and a GPU list with no dates of purchase. The total of 86 GPUs is the sum of the page's list, not a figure that the page prints.

## Limits

The page does not say which nodes or GPUs labs own. It gives no peak performance, no power use and no costs.

> ⚠️ Contradiction: this page gives 6 PB of parallel storage and 6 PB of backup storage. The hardware details page gives "3 PB production and 3 PB backup storage (total 6 PB" ([UCR HPCC hardware details (web)](UCR%20HPCC%20hardware%20details%20%28web%29.md)). The access page also lists "K80" GPUs, which this page does not list ([UCR HPCC access and rates (web)](UCR%20HPCC%20access%20and%20rates%20%28web%29.md)).
