## Citation

California Energy Commission (CEC). "Power Plant Listing", filtered by the technology "Backup Generating System". ## Bottom line

- The CEC power plant listing gives 12 power plants with the technology "Backup Generating System". Four of the names contain "Data Center".
- The page gives the names only, each with a link to the project page. It gives no location, capacity or status.

## Background

The CEC is a California state agency. Its Power Plant Listing is part of its Proceedings pages. It lists power plants in alphabetical order, and a sidebar filters them by proceeding type, project status and technology. This copy is the list with the technology filter "Backup Generating System" only.

## Key claims

- "Following is a list of Power Plants Listed in alphabetical order. Please use the filters on sidebar to refine the list based on technology used by the power plant and the status of the project." (page text)
- "**1 - 12** of **12** power plants." (page text)
- The 12 names are: "AVAIO Pittsburg Backup Generating Facility (PBGF)", "Bowers Backup Generating Facility", "Charcot Avenue Backup Generating Facility", "Lafayette Backup Generating Facility", "Martin Backup Generating Facility (MBGF)", "NorthTown Backup Generating Facility", "RB Inyokern Data Center", "San José Data Center 04", "San Jose Data Center", "Silver Creek Backup Generating Facility (SCBGF)", "STACK SVY03A Data Center Campus" and "Vernon Backup Generating Facility (VBGF)". (list)
- The proceeding types of the filter include "Application for Certification", "Small Power Plant Exemption" and "Opt-In". (sidebar)

## Evidence and method

A filtered list from a state agency's website. It is a count and a set of names on the fetch date. Each name links to a project page on energy.ca.gov. This library does not hold those project pages.

## Limits

- The page does not say which proceeding type or status applies to each facility.
- It gives no city, county, megawatt capacity, fuel or owner. Some names contain a place name, for example "Pittsburg", "Inyokern" and "Vernon", but the list gives no location.
- The page does not say that each backup generating facility serves a data center. Only four names say "Data Center".
- The list can change after the fetch date.
