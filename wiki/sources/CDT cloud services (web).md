# CDT cloud services (web)

## Citation

California Department of Technology. "California Cloud Services." Service web page. https://www.cdt.ca.gov/services/cloud-services/. Copy: [`raw/web/2026-11-11 CDT cloud services.md`](../../raw/web/2026-11-11%20CDT%20cloud%20services.md) (original: `.html` beside it). Read 2026-11-11. No date on the page.

## Bottom line

- The California Department of Technology (CDT) offers state entities three California Cloud Services (CCS). They are California Managed Cloud (CAMC) CDT Managed, CAMC Self-Managed and Unmanaged Cloud Services (UCS).
- These three skip the California Cloud Services Assessment (CCSA). A contracted cloud vendor outside CCS needs the CCSA exemption process under the state's CloudSmart policy.

## Background

This page is CDT's overview of its cloud offerings. It compares the four options in one table and describes the Private Marketplace, a catalog of cloud services that CDT has vetted. The detail of California Managed Cloud (CAMC) is on [CDT California Managed Cloud CAMC (web)](CDT%20California%20Managed%20Cloud%20CAMC%20%28web%29.md). State cloud policy is in [SAM 4983.1 cloud computing (web)](SAM%204983.1%20cloud%20computing%20%28web%29.md).

## Key claims

- "California Department of Technology’s California Cloud Services (CCS) empowers state entities with the confidence of secure, compliant, and expertly managed cloud solutions." (Why California Cloud Services?)
- "If your business or technical needs cannot be met by CDT’s CCS offerings, contracted cloud vendors are also available. However, selecting a contracted cloud vendor requires you to complete the California Cloud Services Assessment (CCSA) exemption process." (Contracted Cloud)
- "CDT’s cloud services uses VMWare Virtual Cloud Foundation (VCF) Infrastructure as a Service (IaaS)." (Note under the comparison table)
- "The Private Marketplace is a state-managed digital catalog – integrated with CAMC and other CDT cloud services – designed to make cloud adoption faster and easier." (Private Marketplace)
- The Private Marketplace sells infrastructure, platform and software as a service (IaaS, PaaS, SaaS). It does not sell "Professional Services" or "Telecommunications" (Private Marketplace Highlights)
- For contracted cloud, "CDT provides" "Cloud account, CPI" and it "Requires formal CCSA approval" (Roles and Responsibilities)

## Evidence and method

A service overview page with a comparison table. "+$" in the table marks a feature that is not in the CDT offering and "may affect total cost". The page gives no prices; the CAMC page does.

## Limits

The page does not name the cloud providers in the Private Marketplace. It gives no figures on use. It does not mention AI or GPU services.
