# TritonAI developer API FAQ (web)

## Citation

UC San Diego, TritonAI. "FAQs." Developer APIs, tritonai.ucsd.edu, date not stated (release information checked October 26, 2026). https://tritonai.ucsd.edu/developer-apis/faq.html. Read 2026-11-09.

## Bottom line

- UC San Diego's TritonAI Gateway gives faculty, staff, researchers and sponsored student projects API access to UC-hosted and cloud AI models. Other UC campuses can use it through an inter-campus recharge agreement.
- UC data from Protection Level 1 to 3 can go on it, but P4 data cannot. Campus administrative use of UC-hosted models costs nothing. Cloud use and research use carry a charge.

## Background

TritonAI is UC San Diego's AI service. The FAQ covers who can ask for access, which data it accepts, the TritonAI Harness client, charges, cloud access and production review.

## Key claims

- "UC San Diego faculty, staff, researchers, and sponsored student projects may submit a request. Other UC campuses may request Gateway access through an inter-campus recharge agreement. CSU, affiliate, and partner requests may also be reviewed." (Who can request TritonAI Developer API access?)
- "The Gateway, TritonGPT, and TritonAI Harness are approved for UC information classified from Protection Level 1 through Protection Level 3 (P1 through P3) when the work is within an approved setup. P4 data is not approved." (What data can I use?)
- "TritonAI Harness is the primary supported client, and Claude Code and Codex are supported alternatives." (Do I have to use TritonAI Harness?)
- "Cloud and UC-hosted access are approved separately." (What's the difference between UC-hosted and enterprise cloud models?)
- "For campus administrative work, UC-hosted token use is covered and not recharged. Cloud use is charged from the first token at the current market rate published in the Model Hub." (How do purpose and funding affect charges?)
- "Research projects charge both UC-hosted and cloud model use to a grant or approved research project chartstring." (How do purpose and funding affect charges?)
- "Cloud access requires a chartstring, named budget owner, and spend limit when the key is issued." (What does a cloud access request require?)
- "A working prototype does not by itself authorize production use." (Can I use the API for a production application?)

## Evidence and method

A service FAQ of about 1,400 words, from the campus provider. It states eligibility, data rules and charging rules. It gives no prices, which are in the model catalog.

## Limits

The FAQ gives no token rates, usage figures or GPU capacity for the UC-hosted models. It does not name the cloud model vendors. The model catalog was not downloaded.
