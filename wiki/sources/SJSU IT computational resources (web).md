# SJSU IT computational resources (web)

## Citation

San José State University (SJSU), Information Technology. "Computational Resources." Web page, "Last Updated Oct 27, 2026". https://sjsu.edu/it/research/resources/compute.php. Read 2026-11-11. Cached copy: `.cache/web/2026-11-11 SJSU IT computational resources.md`.

## Bottom line

- SJSU IT offers a private cloud of virtual servers and storage, and enterprise accounts on Google Cloud Platform (GCP) and Microsoft Azure for research.
- It helps researchers set up High Performance Computing (HPC) in the cloud and hosts HPC systems that colleges buy with grants. The College of Engineering HPC has NVIDIA P-100 GPUs.

## Background

SJSU IT publishes this page in its research section. It names two hosted HPC systems: the College of Engineering (CoE) HPC and the College of Science's WIRC wildfire research environment.

## Key claims

Clouds (sections "SJSU Private Cloud" and "SJSU IT Public Clouds"):

- "SJSU IT provides virtual servers and storage to support the computing environment necessary to host web applications or class setup with custom research software to conduct research-related work."
- "SJSU IT has successfully set up enterprise account and network connectivity for Google Public Cloud GCP and Microsoft Public Cloud Azure so SJSU users can now request research and other academic resources available under GCP and Azure."

HPC support (section "High-Performance Computing Support"):

- "SJSU IT has built a robust cloud infrastructure that enables SJSU's researchers to quickly configure a High Performance Computing (HPC) instance in the cloud, based on their research needs."
- "SJSU IT Data Center is upgraded with additional power and cooling to host additional High Performance Computing (HPC) environments if colleges apply for research grants for the HPC environment."

CoE HPC (same section):

- "A subset of the nodes has additional memory (256 GB per node) and accelerators (NVIDIA P-100 GPUs), making them suitable for some of the most demanding computational tasks."
- "The HPC can only be accessed while connected to the campus network, i.e., SJSU_premier WiFi, on-campus LAN port, or VPN."

## Evidence and method

This is a service page. It describes the services in general terms. It gives no sizes, prices or usage data, except the memory and GPU type of the CoE HPC nodes.

## Limits

- The page does not say who pays for GCP or Azure use.
- It does not give the size of the private cloud or the HPC systems.
- It does not describe the request route beyond "request".
