# Purdue RCAC Gautschi overview (web)

## Citation

Purdue University, Rosen Center for Advanced Computing (RCAC). "Gautschi Overview." User guide page, created August 22, 2025, last updated September 17, 2025. https://docs.rcac.purdue.edu/userguides/gautschi/overview/. Read 2026-11-11.

## Bottom line

- Gautschi is a Purdue "Community Cluster" with CPU nodes and GPU nodes. Its GPU nodes each have eight NVIDIA H100 GPUs.
- Researchers buy access "in units of 48-cores or one quarter share of a CPU node or 5 GPU-year package for GPU nodes".
- All nodes have service "through 2030".

## Background

RCAC publishes this page in its user guides. It describes the Gautschi cluster, its namesake, its node types and its software. The page links a Cluster Access Purchase page and a mailing list for the Community Cluster Program.

## Key claims

- Purpose: "Gautschi is a Community Cluster optimized for communities running traditional, tightly-coupled science and engineering applications." (Gautschi Overview)
- GPU nodes: "GPU compute nodes come with two 56-core Intel Xeon Platinum 8480+ processors, a total of 1031 GB of CPU memory, and eight NVIDIA H100 GPUs, each boasting 80 GB of memory." (Gautschi Overview)
- Service life: "All compute nodes have 400 Gbps NDR Infiniband interconnect and service through 2030." (Gautschi Overview)
- Purchase units: "Access to the Gautschi cluster is being offered in units of 48-cores or one quarter share of a CPU node or 5 GPU-year package for GPU nodes." (Gautschi Overview)
- Purchase route: "To purchase access to Gautschi today, go to the Cluster Access Purchase page." (Gautschi Overview)
- Sub-clusters: sub-cluster A has 338 CPU nodes, and sub-cluster H has 20 nodes with "Eight NVIDIA H100 GPUs (80GB)" (Gautschi Sub-Clusters table)
- Software: "Gautschi nodes run Rocky Linux 9 and use Slurm (Simple Linux Utility for Resource Management) as the batch scheduler for resource and job management." (Gautschi Specifications)

## Evidence and method

This is a technical user guide page. It gives node counts, processor types, memory, interconnect and retirement year, in text and tables. It describes the purchase model of the community cluster but gives no prices.

## Limits

- The page gives no prices for the purchase units.
- It does not say who besides Purdue researchers may buy access.
- It gives the GPU node CPU memory as "1031 GB" in one paragraph, "1032 GB" in the next and "1TB" in the table.
