# Cal-ICOR Acceptable Use Policy (web)

## Citation

Cal-ICOR team. "Cal-ICOR Acceptable Use Policy." Cal-ICOR Documentation, docs.cal-icor.org, date not stated. https://docs.cal-icor.org/acceptable-use. Read 2026-11-09.

## Bottom line

- The policy sets the rules for each "Authorized User" of the infrastructure that Cal-ICOR manages on AWS, Google Cloud and Azure for participating institutions.
- Users must not put sensitive data on it, share accounts, mine cryptocurrency without permission, or monopolize resources. The policy of the user's own institution still applies, and the more restrictive policy wins.

## Background

Cal-ICOR is a JupyterHub teaching service. The policy calls it "a collaboration between the University of California, Berkeley and the California Learning Lab". The page is one of two user policies in the Cal-ICOR documentation. The other is the [Cal-ICOR Privacy Policy (web)](Cal-ICOR%20Privacy%20Policy%20%28web%29.md). See [Cal-ICOR](../entities/Cal-ICOR.md).

## Key claims

- "**Authorized User**: Any individual who has been granted access to Cal-ICOR Managed Infrastructure by a participating Institution." (Terminology)
- "**Cloud Provider**: Any third-party cloud service provider that Cal-ICOR uses to provide computing resources to Authorized Users. This includes, but is not limited to, Amazon Web Services (AWS), Google Cloud Platform (GCP), and Microsoft Azure (Azure)." (Terminology)
- "When other policies that you are bound by are more restrictive than this policy, the more restrictive policy takes precedence." (Acceptable Use Policy)
- "Not store, process or transmit any sensitive data (e.g., grades, personally identifiable information, protected health information, etc.)." (Acceptable Use Policy)
- "Not attempt to use Cal-ICOR Managed Infrastructure for the purposes of mining cryptocurrencies unless explicitly given permission by your Institution Representitive *and* Cal-ICOR staff for research purposes." (Acceptable Use Policy)
- "Cal-ICOR Managed Infrastructure resources are not unlimited. Network bandwidth and storage capacity have finite limits, and all users connected to the network have a responsibility to conserve these resources." (Acceptable Use Policy)
- "Not use the Cal-ICOR Managed Infrastructure in any circumstances where failure could lead to death, personal injury or environmental damage" (Acceptable Use Policy)

## Evidence and method

A user policy of about 780 words, from the program's own documentation. It defines terms and lists user duties. It gives no figures.

## Limits

The policy names no sanction and no review process for a violation. It does not set compute quotas. It gives no date or version.
