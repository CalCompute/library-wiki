# ACCESS Resource Advisor announcement (web)

## Citation

Megan Johnson, National Center for Supercomputing Applications (NCSA). "Meet Your Project's Matchmaker: New ACCESS Tools." ACCESS news story, U.S. National Science Foundation, February 18, 2026. https://access-ci.org/meet-your-projects-matchmaker-new-access-tools/. Read 2026-11-12.

## Bottom line

- The story describes three ACCESS tools that help users choose a resource. They are the Resource Catalog, the ACCESS Resource Advisor (ARA) and the Software Documentation Service (SDS).
- The ARA is "a guided questionnaire". It gives a list of resource options, with wait times for popular resources.
- The SDS shows which resource has which software. A standalone version is free for any institution to use.

## Background

ACCESS is the National Science Foundation (NSF) program that allocates national research computers. This news story on the ACCESS site quotes Sandesh Lamichhane, a systems engineer from the University of Kentucky who helped build the tools. He started on the project as an ACCESS student team leader.

## Key claims

- Catalog: "You can use this tool to sort through the many resources available using filters like AI or specialized support capabilities." (The Resource Catalog and Advisor)
- Advisor: "The ACCESS Resource Advisor (ARA) functions as a guided questionnaire to help narrow your choices to those that would best support your project." (same section)
- Wait times: "Once you’ve filled it out and submitted it, you get a list of resource options. The list even includes the wait times if a resource is particularly popular." (same section)
- Approach: "Instead of approaching it from a resource perspective of ‘this is what we have,’ we approached it from a researcher’s perspective of ‘this is what I need.’" (Lamichhane, same section)
- Use: "There have already been hundreds of recommendations made by the ARA, and we are always looking to improve the ACCESS Resource Advisor" (Lamichhane, same section)
- Software service: "The SDS is a collection of documentation about the various software applications available through ACCESS resources." (The Software Documentation Service)
- Reuse: "They’ve even developed a standalone version of the SDS tool that any institution can use." (same section)
- Cost to users: "If you’re a researcher looking to power your research with HPC at no cost to you, you can get started with the ACCESS program here." (last paragraph)

## Evidence and method

This is a news story by the program about its own tools. It gives one usage figure, "hundreds of recommendations", with no exact count or date range.

## Limits

- The story gives no exact count of ARA users or recommendations.
- It does not say how ACCESS measures wait times.
- It does not give the licence of the standalone SDS tool. It links to a GitHub repository that the library has not read.
