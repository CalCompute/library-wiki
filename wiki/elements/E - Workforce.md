# E - Workforce

## Statutory text

Government Code section 11546.8, subdivision (f)(2)(E), requires the Report to include:

> (E) An analysis of the state's technology workforce and recommendations for equitable pathways to strengthen the workforce, including the role of CalCompute.

Source: [SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md).

## Reading list

This list groups the library's sources for this element by tier. It does not say what the Report will recommend.
