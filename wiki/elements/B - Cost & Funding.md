# B - Cost & Funding

## Statutory text

Government Code section 11546.8, subdivision (f)(2)(B), requires the Report to include:

> (B) An analysis of the cost to the state to build and maintain CalCompute and recommendations for potential funding sources.

Source: [SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md).

## Reading list

This list groups the library's sources for this element by tier. It does not say what the Report will recommend.
