# G - Public Sector Workforce

## Statutory text

Government Code section 11546.8, subdivision (f)(2)(G), requires the Report to include:

> (G) Recommendations regarding how the creation and ongoing management of CalCompute can prioritize the use of the current public sector workforce.

Source: [SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md).
