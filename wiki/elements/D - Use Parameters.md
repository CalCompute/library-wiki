# D - Use Parameters

## Statutory text

Government Code section 11546.8, subdivision (f)(2)(D), requires the Report to include:

> (D) Recommendations for the parameters for use of CalCompute, including, but not limited to, a process for determining which users and projects will be supported by CalCompute.

Source: [SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md).
