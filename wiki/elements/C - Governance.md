# C - Governance

## Statutory text

Government Code section 11546.8, subdivision (f)(2)(C), requires the Report to include:

> (C) Recommendations for the governance structure and ongoing operation of CalCompute.

Source: [SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md).

## Reading list

This list groups the library's sources for this element by tier. It does not say what the Report will recommend.
