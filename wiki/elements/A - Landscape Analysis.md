# A - Landscape Analysis

## Statutory text

Government Code section 11546.8, subdivision (f)(2)(A), requires the Report to include:

> (A) A landscape analysis of California's current public, private, and nonprofit cloud computing platform infrastructure.

Source: [SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md).

## Reading list

This list groups the library's sources for this element by tier. It does not say what the Report will recommend.
