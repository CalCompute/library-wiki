# CalCompute as coordinator vs operator

_This page reports what the sources say. It is not a position of the consortium._

## Positions

- **Integrate, not build.** SDSC says the national plan is to "integrate leading existing capabilities rather than build isolated infrastructure" ([SDSC NAIRR Operations Center launch](../sources/SDSC%20NAIRR%20Operations%20Center%20launch.md)).
- **Operator.** The statute requires "A fully owned and hosted cloud platform" and staff "to operate and maintain" it ([SB-53 Gov Code 11546.8](../sources/SB-53%20Gov%20Code%2011546.8.md)). The 2025 Floor analysis expected UC "to operate CalCompute" if placed there ([2026-10-14 SB-53 Assembly Floor analysis, p. 7](../sources/2026-10-14%20SB-53%20Assembly%20Floor%20analysis.md)).
