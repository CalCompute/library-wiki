# California Cradle-to-Career Data System

## Bottom line

- The California Cradle-to-Career Data System (C2C) links education and workforce data that its data partners already hold. It does not collect new data from students or families ([C2C Request Access to Data (web)](../sources/C2C%20Request%20Access%20to%20Data%20%28web%29.md)).

## Why they matter

- C2C has three data tiers: Query Builder, Expedited and Comprehensive Data Requests ([C2C DTAB 5 research request and secure enclave update (web)](../sources/C2C%20DTAB%205%20research%20request%20and%20secure%20enclave%20update%20%28web%29.md), p. 1).
- An expedited request gets a data file in one month. A comprehensive request gets preliminary approval in three months ([C2C Request Access to Data (web)](../sources/C2C%20Request%20Access%20to%20Data%20%28web%29.md)).
- Its secure data enclave is to give approved researchers "a secure compute environment" ([C2C DTAB 5 research request and secure enclave update (web)](../sources/C2C%20DTAB%205%20research%20request%20and%20secure%20enclave%20update%20%28web%29.md), p. 3). C2C chose the NORC Data Enclave ([NORC Cradle-to-Career data enclave (web)](../sources/NORC%20Cradle-to-Career%20data%20enclave%20%28web%29.md)).
