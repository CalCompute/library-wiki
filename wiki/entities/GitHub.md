# GitHub

## Bottom line

- GitHub hosts public software repositories. Its REST API (application programming interface) gives a record for each repository ([vLLM GitHub repository record (web)](../sources/vLLM%20GitHub%20repository%20record%20%28web%29.md)).

## Why they matter

- Each record gives the owner, licence, dates and counts of stars and forks ([vLLM GitHub repository record (web)](../sources/vLLM%20GitHub%20repository%20record%20%28web%29.md)).
- On 2026-11-11, the records gave these star counts:
  - vLLM: 96,755 ([vLLM GitHub repository record (web)](../sources/vLLM%20GitHub%20repository%20record%20%28web%29.md)).
  - LibreChat: 46,991 ([LibreChat GitHub repository record (web)](../sources/LibreChat%20GitHub%20repository%20record%20%28web%29.md)).
  - OpenCode: 226,106 ([OpenCode GitHub repository record (web)](../sources/OpenCode%20GitHub%20repository%20record%20%28web%29.md)).
