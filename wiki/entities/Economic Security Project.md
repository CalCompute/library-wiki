# Economic Security Project

## Bottom line

- The Economic Security Project (ESP) is a national organization. Economic Security California (ESCA) is its California state affiliate ([ESP launches Economic Security California 2024-01-30 (web)](../sources/ESP%20launches%20Economic%20Security%20California%202024-01-30%20%28web%29.md)). As "Economic Security California Action", it co-sponsored SB-53 and calls CalCompute "a public option for cloud computing".

## Why they matter

- Economic Security California Action co-sponsored SB-53 and frames CalCompute as "a public option for cloud computing" ([Wiener SB-53 expansion release 2025-07-09](../sources/Wiener%20SB-53%20expansion%20release%202025-07-09.md)).
- The group says computing power for advanced AI "is dominated by just three companies: Amazon, Google, and Microsoft". It says CalCompute "will provide a public option, dilute this concentrated market" ([ESP Governor signs SB-53 release 2025-09-29 (web)](../sources/ESP%20Governor%20signs%20SB-53%20release%202025-09-29%20%28web%29.md)).
