# California Legislature

## Bottom line

- The California Legislature makes the state's statutes. Its website, California Legislative Information, publishes bill texts and code sections ([AB 979 AI cybersecurity bill text](../sources/AB%20979%20AI%20cybersecurity%20bill%20text.md); [Gov Code 53051](../sources/Gov%20Code%2053051.md)).

## Why they matter

- AB 1405 (2026) makes the Government Operations Agency set up an AI Auditor Registry by Jan. 1, 2029 (C) ([AB 1405 bill text](../sources/AB%201405%20bill%20text.md)).
- SB 813 (2026) makes the same agency set criteria for independent verification organizations that assess AI risks by Jan. 1, 2028 (C) ([SB 813 bill text](../sources/SB%20813%20bill%20text.md)).
- SB 1119 (2026) requires risk assessments and independent child safety audits for companion chatbots (C, D) ([SB 1119 companion chatbot child safety bill text](../sources/SB%201119%20companion%20chatbot%20child%20safety%20bill%20text.md)).
- AB 979, enrolled in 2025, requires a California AI Cybersecurity Collaboration Playbook by Jan. 1, 2027 (C, D) ([AB 979 AI cybersecurity bill text](../sources/AB%20979%20AI%20cybersecurity%20bill%20text.md)).
- SB 896 (2024) sets rules for state use of generative AI. State GenAI messages to the public must say so (C, D, G) ([SB 896 Generative AI Accountability Act bill text](../sources/SB%20896%20Generative%20AI%20Accountability%20Act%20bill%20text.md)).
- The Constitution forbids gifts of public money and state stock ownership (B, C) ([California Constitution art XVI sec 6](../sources/California%20Constitution%20art%20XVI%20sec%206.md)). One statute defines small businesses for state contracts (B, F) ([Gov Code 14837](../sources/Gov%20Code%2014837.md)). Another makes public agencies file with the Registry of Public Agencies (C) ([Gov Code 53051](../sources/Gov%20Code%2053051.md)).
