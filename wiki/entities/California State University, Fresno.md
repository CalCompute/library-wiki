# California State University, Fresno

## Bottom line

- Carnegie lists it as California State University-Fresno in Fresno, California. Its 2025 Institutional Classification is "Mixed Undergraduate/Graduate-Master's Large/Medium" ([Carnegie 2025 Public Data File (web)](../sources/Carnegie%202025%20Public%20Data%20File%20%28web%29.md)).
