# Cloud Native Computing Foundation

## Bottom line

- The Cloud Native Computing Foundation (CNCF) keeps the CNCF landscape. It is a public list of cloud-native and AI projects, products and members ([CNCF landscape data file (web)](../sources/CNCF%20landscape%20data%20file%20%28web%29.md)).

## Why they matter

- The landscape data file read on 2026-11-11 has 2,444 items in 15 categories. 41 are CNCF graduated projects, 37 incubating and 156 sandbox ([CNCF landscape data file (web)](../sources/CNCF%20landscape%20data%20file%20%28web%29.md)).
- Five categories are on AI, among them Inference, which lists vLLM ([CNCF landscape data file (web)](../sources/CNCF%20landscape%20data%20file%20%28web%29.md)).
