# raw/legislative

The statute and the legislative record of SB 53 and the bills before it: committee analyses, the signing message and press releases from the author and the Governor. All are government documents (`rehost: yes`), and `sourceUrl` in the frontmatter is the official record.

- A file with `passages:` is a full copy, word for word. `passages` gives its CalCompute passages as file line numbers; the Drive's "0 - LEGISLATIVE CONTENTS" quotes those lines.
- A file with `excerpt_lines:` is an excerpt, word for word. `[...]` marks a cut. The statute, `SB-53 Gov Code 11546.8.md`, is § 11546.8 only; the full bill is `SB-53 chaptered 2025-09-29.md`. The rest of SB 1047 is in its PDF. The full Assembly Floor and Senate GO analyses are in `raw/shared/` and `raw/web/`.
