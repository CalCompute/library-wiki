# raw/shared

Documents the consortium's research used before this library started, copied when it was set up on Nov. 1, 2026. Nothing new goes here: new documents go in `raw/web/`. Only rehosted files are here: government documents and files with an open license. Frontmatter: `url`, `fetched`, `publisher`, `published`, `original`, `license` (if any), `rehost: yes`.
