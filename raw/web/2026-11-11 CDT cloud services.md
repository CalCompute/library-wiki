## Why California Cloud Services?

California Department of Technology’s California Cloud Services (CCS) empowers state entities with the confidence of secure, compliant, and expertly managed cloud solutions.

**Discover the benefits:**

![](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/No-CCSA-2.png)

Skip the Paperwork
:   Using CCS lets you bypass the California Cloud Services Assessment (CCSA) process so you can get started faster.

![](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/CCS-Compliance.png)

Statewide Security & Compliance
:   Built on secure, scalable infrastructure managed by CDT, with full alignment to California's strict IT policies and zero trust standards.

![](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/CCS-Security-300x300.png)

Embedded Security Controls
:   Centralized monitoring and incident response embedded in every service.

![](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/CCS-data-residency.png)

Meets Data Residency & Privacy Requirements
:   Hosting, storage, and backup solutions through state-approved providers, always supporting California's regulatory mandates.

![](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/CCS-support.png)

Predictable Costs & Expert Support
:   Stable pricing, trusted expert support from CDT for all of your cloud needs.

![](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/CCS-marketplace.png)

Private Marketplace
:   Access a curated catalog of secure, compliant cloud services vetted and pre-approved by CDT, ensuring streamlined procurement and simplified service selection.

### [Contracted Cloud](https://www.cdt.ca.gov/services/off-premises-cloud/)

If your business or technical needs cannot be met by CDT’s CCS offerings, contracted cloud vendors are also available. However, selecting a contracted cloud vendor **requires you to complete the California Cloud Services Assessment (CCSA) exemption process**. This process is designed to ensure your request is reviewed and formally approved in alignment with the state’s CloudSmart policy, helping to maintain security, compliance, and strategic IT management for California government organizations.

## Private Marketplace

![Private marketplace icon](https://www.cdt.ca.gov/services/wp-content/uploads/sites/2/2026/01/CCS-marketplace.png)The **Private Marketplace** is a state-managed digital catalog – integrated with CAMC and other CDT cloud services – designed to make cloud adoption faster and easier. It provides a Cloud Provider specific Marketplace where you can **browse, select, and deploy** a growing range of cloud services and solutions without the usual procurement delays.

### Benefits

**Streamlined Procurement with Confidence**Everything in the Private Marketplace is already curated and vetted by CDT to ensure they meet essential state requirements – so you can purchase quickly and innovate without unnecessary risk.

**Rapid Deployment**Services are Cloud Native for easy implementation, helping you move to operational use in record time.

**Expanding Choices**Private Marketplace is continuously updated with new technologies, giving you access to modern solutions as soon as they’re available.

### Private Marketplace Highlights

Explore key categories in this table. To browse the full inventory of Private Marketplace, sign in with your CDT Cloud Services account.

| Software or Service | Private Marketplace Purchase |
| --- | --- |
| Infrastructure as a Service (IaaS) | ✓ Yes |
| Platform as a Service (PaaS) | ✓ Yes |
| Software as a Service (SaaS) | ✓ Yes |
| Professional Services | X No |
| Software Licenses used outside of your cloud environment\* | X No |
| Telecommunications | X No |

\*Software licenses intended for the use outside of your CDT approved cloud environment (e.g., Windows 11 desktop, MS Teams, etc.) should be purchased using the designated and approved state contract procurement vehicles.

### Need something not listed?

If you don’t see a service or function you need in Private Marketplace, simply submit a [Cloud Marketplace Purchases](https://services.cdt.ca.gov/csm?id=sc_cat_item&sys_id=9d093d011b29ee102635db1ee54bcbc8) Case/Request in the CDT IT Service Portal.

Our team will review and work to make it available (if aligned to contract terms and procurement policies), ensuring you have the flexibility to get the right solution when you need it.

Here is a high level side-by-side cloud service comparison showing which tasks you manage, where CDT provides expert help, and what kinds of efforts each option fits best.

Applications and settings

Servers, OS, security, compliance, networking, infrastructure
