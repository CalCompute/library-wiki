# Query

The rules in [AGENTS.md](../../../AGENTS.md) apply to every step.

1. Read `wiki/index.md`, then the pages it points to.
2. Answer with citations to source pages. Say what the sources say, side by side. Do not recommend.
3. For an approved visitor question, file the answer in `wiki/analyses/<short title>.md` in the format above. Update the index, set the suggestion's status to `answered`, and add a `query |` log entry.
